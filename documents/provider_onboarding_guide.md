# Provider Onboarding Guide

## Overview

This guide describes how a new provider organization (a hospital, clinic,
or multi-specialty group) is onboarded onto the MedFlow platform. Provider
onboarding is owned by the Provider Support team and typically takes two
to four weeks depending on the provider's size and existing systems.

## Onboarding Steps

1. **Identity verification.** The provider organization submits proof of
   licensure and NPI numbers for all practicing providers.
2. **Data processing agreement.** The provider signs MedFlow's data
   processing agreement before any patient data is migrated.
3. **System configuration.** MedFlow configures the provider's scheduling
   rules, user roles, and integration endpoints.
4. **Staff training.** Provider staff complete platform training sessions
   before go-live.
5. **Go-live.** The provider organization is switched to production use
   and monitored closely for the first two weeks.

## Common Onboarding Failures

The most frequent onboarding blockers are incomplete NPI documentation and
delays in signing the data processing agreement. Both should be flagged to
the assigned Provider Support Engineer immediately.
